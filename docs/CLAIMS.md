| Claim | Status | Evidence / limitation |
|---|---|---|
| Four native UPX implementations agree on tested Linux fixtures | Demonstrated | quad-mining-20261011: known answers and native comparisons |
| Four public networks accept the proposed carrier today | Not demonstrated | Current deployed state and full consensus validation outstanding |
| UPX carrier rewards can be paid and spent | Not demonstrated | v1 scanner guard and decoy availability remain gates |
| DEGO/XKR ordinary auxiliary tree collides | Demonstrated on pinned native paths | pilot: identical selector, 30 paired cases |
| Different genesis coinbase text alone proves different chains | False inference | Full genesis construction and selector rules matter |
| Height-gated selector separation works in the isolated lab | Demonstrated | DEGO boundary tests, dual real-daemon receipts and replay |
| Shared parent envelope eliminates second PoW | False for tested DEGO/XKR algorithms | Both complete hash functions evaluated |
| Initialization prefix can be reused correctly | Demonstrated | native known-answer comparisons and reuse fixtures |
| Shared initialization delivers major speedup | Not supported | direct/snapshot overhead; standalone control isolates tiny residual |
| Interleaving outperforms specialized sequential execution | Not supported in tested runs | interleave confirmation loses 12/12 |
| Research demonstrates energy savings | Not demonstrated | no energy measurements |
| DEGO currently accepts dual UPX2/Turtle PoW from this work | No | later work is simulation, not daemon deployment |
| Kerrigan LWMA port agrees with selected native oracle cases | Demonstrated | 9 selected vectors, 256 generated cases |
| Kerrigan's complete consensus/security was reproduced | No | HMP, deployed state and full node suite not covered |
| Return burst alone makes a DAA unacceptable | Rejected evaluation criterion | full response/hopping/recovery analysis required |
| Real thread-step LWMA experiment was completed | No | proposed only; retained nodes use fixed difficulty |
| Testnets retained at publication | Observed | six running containers; node1 tips 19 and15 |

Evidence folder names and entry-point links are in the [experiment ledger](EXPERIMENTS.md). Results are scoped to fixtures, hardware and revisions; these statuses are not universal proofs.
