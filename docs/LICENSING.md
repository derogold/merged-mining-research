# Source attribution and licensing

This is a mixed research archive. Upstream source copies, generated wrappers containing upstream code, and patches retain their existing copyright and license obligations. Consult original file headers and pinned repositories before reusing or distributing derived software. In particular, Kerrigan's upstream license is preserved within its experiment bundle; DEGO, XKR, WRKZ, XFG and UPX source references are pinned in the paper and individual reports.

No blanket license is applied to this repository because it would risk implying a relicensing of third-party material. New research prose and harness distribution terms have not been selected by the owner. Private archival publication does not settle future public distribution terms. A public release should include a complete third-party notice review.
